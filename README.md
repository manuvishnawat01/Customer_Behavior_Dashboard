---

## 📊 Interactive Dashboard Preview

An interactive, beginner-friendly **Customer Behavior & Food Analytics Dashboard** matching modern Power BI design standards.

### Features
- 🔄 **Dynamic Slicers**: Filter by Subscription Status (Membership), Gender, Cuisine Categories, and City Locations.
- 📈 **Key Metrics**: Total Orders, Average Purchase Amount (AOV), Average Review Rating.
- 🍕 **Category Analytics**: Revenue and Sales Volume by Cuisine (Pizza, Biryani, Fast Food, Chinese, etc.).
- 👥 **Customer Demographics**: Revenue and Sales Volume by Age Group (`Young Adult`, `Middle-aged`, `Adult`, `Senior`).
- 📥 **One-Click Export**: Export filtered data directly to CSV.

## 🚀 How to Run & View

### 1. View Interactive Web Dashboard
Double-click `PowerBI_Report/index.html` in any web browser to interact with the live dashboard immediately.

### 2. View in Power BI Desktop
1. Open **Power BI Desktop**.
2. Open `PowerBI_Report/Food_Delivery_Analytics_Dashboard.pbix`.
3. Import data from `PowerBI_Report/FoodOrders_Cleaned.csv`.

### 3. Run SQL Queries
Execute `SQL/SQLQuery8_Manu.sql` in **Microsoft SQL Server Management Studio (SSMS)** connected to the `FoodDeliveryAnalytics` database.
